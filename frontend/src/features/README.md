# Features Directory (Feature-Sliced Modular Boundaries)

- `auth/`: Authentication UI & state placeholders
- `map/`: MapLibre GL map viewport & spatial overlay placeholders
- `navigation/`: Destination input & route card placeholders
- `safety/`: Safety score & confidence indicators placeholders
- `journey/`: Safe Journey mode control bar placeholders
- `companion/`: Check-in modal & prompt response placeholders
- `alerts/`: Toast & audio alert UI placeholders
- `community/`: Hazard report submission form placeholders
- `vehicle/`: Ride-share plate input modal placeholders
- `image-analysis/`: Surroundings camera scan modal placeholders
