# Product Requirements Specification (PRS) — Version 1.1

## Baseline Summary

SafePath is a preventive safety intelligence and journey companion platform. The product prioritizes **risk estimation, risk avoidance, transparency, and user privacy**.

### Core Requirements Included (MoSCoW):
* **Must Have:** Safety-aware route recommendation, location/segment safety scores, historical incident processing, community safety reports, time-based risk modeling, safety score confidence level, explainable route recommendations, Safe Journey Mode with explicit session consent, route deviation detection, dynamic in-transit reassessment, contextual safety alerts, configurable periodic companion check-ins, multi-tier privacy data lifecycle.
* **Should Have:** Infrastructure data layers (streetlights, CCTV, transport nodes), user-controlled surroundings image analysis, vehicle metadata registration for active journeys.

### Key Governance:
* **Prevention First:** Emergency escalation is a secondary backup layer; preventive routing is primary.
* **Privacy by Design:** Location tracking is strictly opt-in, session-bounded, and ephemeral.
