# SafePath Frontend Client

React 18 + TypeScript + Vite Single Page Application for SafePath.

## Structure
* `src/app/`: Core app components and router definitions.
* `src/components/`: Shared UI components.
* `src/pages/`: Main application pages.
* `src/features/`: Feature-sliced domain modules (auth, map, navigation, safety, journey, companion, alerts, community, vehicle, image-analysis).
* `src/hooks/`: Custom React hooks.
* `src/services/`: API integration services.
* `src/types/`: TypeScript interfaces and data models.
* `src/utils/`: Utility functions.

## Running Locally
```bash
npm install
npm run dev
```
Development Server: `http://localhost:5173`
